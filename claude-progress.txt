### Verified Features
1. **Feature #36 - Scene reordering in wizard** - PASSED
   - Fixed Express route ordering bug: `/scenes/reorder` was after `/:sceneId` route
   - Fixed unique constraint violation with transaction-based two-pass update
   - Test verified:
     - Created project with 10 scenes ✓
     - Scene 3 moved to position 1 via API ✓
     - Scene 5 moved to position 2 via API ✓
     - Order persists on refresh (verified via fresh fetch) ✓

### Technical Fixes Applied
1. **Route Ordering in scenes.js**:
   - Moved `PUT /:id/scenes/reorder` route BEFORE `PUT /:id/scenes/:sceneId`
   - Added comment: `// MUST be before :sceneId route to avoid conflict`
   - Express matches routes in order, so "reorder" was being matched as `:sceneId`

2. **Unique Constraint Fix**:
   - Database has `@@unique([projectId, sequenceNumber])` constraint
   - Reordering caused "record already exists" errors
   - Solution: Transaction with two passes:
     - Pass 1: Set all sequenceNumbers to negative values (-1, -2, -3...)
     - Pass 2: Set all sequenceNumbers to correct positive values (1, 2, 3...)
   - This avoids constraint violations during the update

2. **Feature #67 - Toast notifications disappear automatically** - PASSED
   - react-hot-toast v2.4.1 with default Toaster configuration
   - Success toasts auto-dismiss after 2000ms (default)
